# Google Play — всё для публикации Ghostly VPN

Всё ниже уже подготовлено в репозитории. Что нужно сделать руками — только то, что требует
аккаунта владельца (оплата, подтверждение личности, нажатия в консоли).

## 0. Аккаунт разработчика (один раз)
1. https://play.google.com/console/signup — тип **«Личный» (Personal)**.
2. Взнос **25 $** один раз, подтверждение личности по документу.
3. У новых личных аккаунтов Google требует **закрытое тестирование: 12 тестировщиков, 14 дней подряд**,
   и только после этого открывает публикацию в «Рабочую версию». Тестировщики — любые люди с Android
   и Gmail (друзья, пользователи из бота): добавляются по e-mail в «Тестирование → Закрытое».

## 1. Сборка
```
./gradlew :androidApp:bundlePlay
```
Файл: `androidApp/build/outputs/bundle/play/androidApp-play.aab` (подписан тем же ключом, что и APK).
Это отдельная сборка для Play: **без самообновления** (Play запрещает обновляться в обход магазина),
**без `QUERY_ALL_PACKAGES`** (список приложений для раздельного туннеля берётся через запрос лаунчера).
Обычный APK для сайта/GitHub не меняется.

При первой загрузке включите **«Подписание приложений в Google Play»** и выберите
«Использовать ключ, которым подписан загруженный пакет» — тогда APK с сайта и из Play будут совместимы.

## 2. Страница в магазине
Всё лежит в `fastlane/metadata/android/{ru-RU,en-US}/`:
- `title.txt`, `short_description.txt` (≤ 80), `full_description.txt`
- `images/icon.png` (512×512), `images/featureGraphic.png` (1024×500)
- `images/phoneScreenshots/1.png`, `2.png`

Категория: **Инструменты (Tools)**. Контакты: e-mail владельца, сайт `https://ghostlinknex.online`.
Политика конфиденциальности: **https://srv.ghostlinknex.online/docs/policy** (раздел 2.1 — про приложение).

## 3. Содержание приложения (App content)

### Декларация VpnService
- Основная функция приложения — VPN: **да**.
- Описание: «Ghostly VPN — клиент с открытым исходным кодом на ядре Xray. Через VpnService приложение
  направляет трафик устройства на VPN-сервер из подписки, которую пользователь добавил сам (по ссылке,
  из буфера обмена или по QR-коду). Приложение не собирает, не продаёт и не использует данные трафика,
  не показывает рекламу и не меняет трафик для монетизации.»
- Видео-демонстрация (если попросят): запись экрана — добавить подписку → нажать на призрака →
  системный запрос VPN → «Подключено».

### Фоновая служба (foreground service, `specialUse`)
Тип: `specialUse`, подтип `vpn`. Объяснение: «Служба держит VPN-туннель, пока пользователь включил VPN;
показывает постоянное уведомление со скоростью и кнопкой отключения.»

### Безопасность данных (Data safety)
- Собирает ли приложение данные: **да** — только одно:
  - **Идентификаторы устройства** → «ID устройства или другие ID»: *собирается*, **не передаётся третьим лицам**,
    обязательно, цель — **«Функциональность приложения»** и **«Предотвращение мошенничества, безопасность»**
    (лимит устройств по подписке). Передаётся в хэшированном виде.
- Данные шифруются при передаче: **да** (HTTPS).
- Пользователь может запросить удаление: **да** (через поддержку @GhostlySupportBot).
- Местоположение, контакты, фото, история браузера, содержимое трафика — **не собираются**.
- Список установленных приложений — **используется только на устройстве**, не передаётся
  (в Data safety это не считается «сбором»).

### Рейтинг (анкета IARC)
Категория «Утилиты / инструменты». Насилие, секс, ненормативная лексика, азартные игры, контент
от пользователей, покупки внутри приложения — **нет**. Итог обычно 3+ / PEGI 3.

### Прочее
- Реклама: **нет**. Целевая аудитория: **18+** (так проще с правилами для VPN).
- Государственное приложение: нет. Финансовые функции: нет. Приложение для здоровья: нет.
- Доступ для проверки (App access): вход не нужен, но для работы нужна подписка —
  в поле для проверяющих дайте **тестовую ссылку подписки** (создать в админке бота на 30 дней),
  иначе модерация увидит «приложение не работает».

## 4. Частые причины отказа и что уже сделано
| Причина | Статус |
|---|---|
| Самообновление в обход Play | отключено в сборке `play` |
| `QUERY_ALL_PACKAGES` без веской причины | удалено, вместо него `<queries>` |
| Нет политики конфиденциальности / не про приложение | раздел 2.1 на сайте |
| Не заполнена декларация VPN | текст выше |
| Проверяющий не может проверить работу | дать тестовую подписку в App access |

## Важно про Россию
Роскомнадзор регулярно требует от Google убрать VPN-приложения из российского Play. Если это случится,
приложение останется доступным в других странах, а в России — через сайт, GitHub и IzzyOnDroid.
